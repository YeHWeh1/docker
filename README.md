## 五、快速开始

```powershell
# 1. 启动环境
docker compose up -d

# 2. 确认服务可用（能列出 ydsh_ods 才算成功）
docker exec hive-server beeline -u "jdbc:hive2://localhost:10000" -e "show databases;"

# 3. 一键跑完清洗并展示结果
.\scripts\run-all.ps1
```

或者直接双击 `一键运行.bat`。

> `模拟数据/` 目录需要自行放入 6 个 CSV（`ods_user.csv` 等），
> 容器内通过 `/data` 挂载读取。数据文件按任务书要求不入版本库。

## 七、说明

- **ODS 层保留原始数据**：原始表不做任何修改，便于回溯与对比。
- **清洗采用 CTAS**：Hive 非事务表不支持 UPDATE，清洗通过重建表实现，脚本可重复执行。
- **异常只标记不改值**：负金额、负数量、枚举混用等需要业务规则确认，本周仅加标记列，留待后续周次统一规范化。
